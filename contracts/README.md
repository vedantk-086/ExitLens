# Generated API Contract Artifacts

This directory is reserved for generated contract artifacts. After the FastAPI route and Pydantic models have been implemented, export the actual application OpenAPI document here as `openapi.json`. Generate frontend TypeScript types from that file.

Do **not** create an empty or guessed OpenAPI file now. The API contract to implement is documented in [`../docs/API_CONTRACT.md`](../docs/API_CONTRACT.md).
